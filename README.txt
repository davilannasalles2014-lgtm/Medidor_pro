MEDIDOR PRO PREMIUM — GITHUB PAGES

Este pacote está pronto para ser publicado no GitHub Pages.

Arquivos:
- index.html: site completo em um único arquivo.
- .nojekyll: evita processamento desnecessário do GitHub Pages.

Depois de publicar, o endereço será HTTPS, e a câmera poderá ser autorizada pelo navegador.

IMPORTANTE:
A câmera do navegador exige HTTPS (ou localhost). Depois de publicar no GitHub Pages,
abra o endereço https://... no Chrome e permita o acesso à câmera.

A medição usa calibração por referência. A precisão real depende da câmera, foco,
perspectiva, distância, iluminação e qualidade da calibração; não há garantia de ±1 mm.
